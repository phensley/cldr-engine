DateTimePatternFieldType

A single character representing a field in a date.

'G' | 'y' | 'M' | 'd' | 'a' | 'B' | 'H' | 'h' | 'm' | 's'

Values​

  • "G"
    • Era
  • "y"
    • Year
  • "M"
    • Month
  • "d"
    • Day
  • "a"
    • Day period (AM, PM)
  • "B"
    • Day period flexible (e.g. "in the afternoon")
  • "H"
    • Hour (24-hour cycle)
  • "h"
    • Hour (12-hour cycle)
  • "m"
    • Minute
  • "s"
    • Second
